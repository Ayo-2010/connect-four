# Connect Four — Tabletop

A warm, tactile Connect Four board with a competent computer opponent and a two-player mode.

## Features

- Seven-column, six-row board with animated disc drops
- Computer opponent that wins, blocks and favours the centre
- Two-player local mode with a shared scoreboard
- Horizontal, vertical and diagonal win detection with highlighted discs
- Session win totals and a saved best streak
- Mouse, touch and number-key controls
- New game and reset-score buttons
- A clear turn indicator for both modes

- A How to play popup with the controls and scoring rules.

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
